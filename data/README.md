# Dados de exemplo

[`editais/`](editais/) contém critérios transcritos em JSON e uma lista de editais em CSV. Cada exemplo conserva os campos e as fontes registrados durante a pesquisa. A interpretação das regras deve ser conferida no documento de origem.

`briefing-exemplo-energia.json` representa o cenário de exemplo do desafio. Os dados usados na aplicação são fictícios e estão em [`prototype/aptus-demo/src/demo/`](../prototype/aptus-demo/src/demo/).

`raw/` é o local reservado a documentos de entrada para uso local dos scripts. Seu conteúdo é ignorado pelo Git. Os currículos recebidos no desafio e suas extrações não são distribuídos.

O [guia dos scripts](../src/README.md) explica como fornecer documentos próprios e reproduzir a pesquisa. O [relatório exploratório](../docs/analise-base.txt) apresenta contagens e identificadores anonimizados.

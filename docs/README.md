## Materiais do evento

[Entrega 2026](entrega-2026/README.md) reúne resumos, formatos editáveis, diagramas e pacotes para download. [Vídeos e gravação](video/README.md) aponta para o pitch final, versões anteriores e arquivos de edição.

O [arquivo de preparação](arquivo/README.md) conserva a proposta inicial e os registros de trabalho. Pendências e prazos nesses registros descrevem a situação na data em que foram escritos. Lastro é o nome anterior do Aptus; os caminhos em `lastro-3.1/` e `entrega/` foram mantidos para facilitar a consulta a referências antigas.

A [lista completa de arquivos](INDICE_DE_ARQUIVOS.md) permite localizar também códigos, imagens, versões anteriores e relatórios de verificação.

# Resumo no modelo do HackatOhm

Versão de duas páginas preparada pela equipe Quatro e meio para o desafio D03 da EloGroup. O vídeo está na [release do pitch final](https://github.com/santana-iago/hackatohm/releases/tag/pitch-v4).

| Arquivo | Uso |
| --- | --- |
| [Resumo em PDF](D03_Quatro_e_meio_Resumo.pdf) | Leitura. |
| [Word editável](D03_Quatro_e_meio_Resumo.docx) | Edição do texto e da figura. |

O documento reúne síntese, problema, solução, fundamentação, resultados ilustrativos, cooperação e fontes. As projeções econômicas dependem de validação em piloto.

## Conferências da versão preparada para o evento

| Elemento | Contagem |
| --- | ---: |
| Título | 7 palavras |
| Síntese | 137 palavras |
| Problema e objetivo | 57 palavras |
| Solução proposta | 94 palavras |
| Fundamentação | 59 palavras |
| Resultados obtidos | 30 palavras |
| Resultados esperados | 30 palavras |
| Cooperação | 183 palavras, em um parágrafo |

As contagens excluem títulos e rótulos. A figura mede 16,8 × 3,1 cm. Ao alterar o Word, exporte novamente o PDF e confira a distribuição das duas páginas.

Os geradores da [versão anterior](../README.md) não reproduzem este modelo. O [índice geral](../../README.md) reúne os demais materiais do projeto.
